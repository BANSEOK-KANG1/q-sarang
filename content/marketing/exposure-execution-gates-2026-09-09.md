- 홈·연구 원칙·대표 논문·robots·16 URL 사이트맵·큐사랑 문의 허브 링크 검증 완료

- 예전 로고 파일 주소 3개는 삭제하지 않고 Q-LOVE 이미지로 응답하도록 배포 호환 처리를 준비했다.

### 2. 소유 소셜 채널 게시

필요 정보:

```text
Instagram: [계정 URL 또는 사용 안 함]
Threads: [계정 URL 또는 사용 안 함]
Facebook: [페이지 URL 또는 사용 안 함]

```

로그인된 실제 소유 계정만 사용한다. 고객 정보 글에는 창업 연락처를 넣지 않고 창업·상품 허브에서만 문의 코드를 표시한다.

제왕충초·코디세핀 연구 유입용 자산은 `content/marketing/q-love-research-distribution/q-love-research-distribution-pack.md`에 정리했다. 카드 3장은 사람·동물·세포·리뷰를 구분하고 연구 결과와 제품 라벨을 분리해 확인하도록 구성했으며, 확인되지 않은 효능 문구는 넣지 않았다.

30일 통합 실행 순서와 세 유입 여정의 판정 기준은 `content/marketing/q-love-30-day-growth-dashboard-2026-09-10.md`에서 관리한다. 창업 질문표 외부 배포 문구는 `content/marketing/startup-hub-distribution-pack-2026-09.md`에 분리해 고객용 콘텐츠와 연락처가 섞이지 않게 했다.

## 우선순위

1. Q-LOVE 변경본의 홈 재수집을 네이버에 한 번 요청하고 72시간 동안 반영을 기다린다.
2. 9/11 검색글 공개 직후 `#뿌리염색` 추가와 기존 헤어라인 글 연결
3. 소유 소셜 1곳에서 카드 2장 또는 15초 영상 한 편만 시험 배포
4. `qlovechangup` 블로그가 사용자 소유·운영 채널인지 확인된 경우에만 질문이 일치하는 원문 링크를 1회 연결
5. 실제 지점 1곳을 확인해 지역 검색·플레이스·첫 방문 허브를 연결
6. 24시간·72시간·7일 단위로 검색어→원문→허브→문의 코드 흐름 측정

확인된 지점이 생기기 전까지는 처음 방문 허브에 시·구 정도의 지역 수요만 받는 댓글 문구를 후보로 둔다. 고객을 창업 상담 번호로 보내거나 예약 가능성을 약속하지 않는다. 문구와 답변 기준은 `content/marketing/customer-region-demand-capture-2026-09.md`에 준비했으며 공개 적용은 별도 승인 대상이다.
