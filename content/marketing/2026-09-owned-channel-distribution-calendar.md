# 큐사랑 9월 검색 유입·소유 채널 배포 캘린더

목적: 새 글을 발행하고 끝내지 않고, 검색 원문 → 카드 저장 → 블로그 재방문 → 처음 방문 안내로 이어지게 한다. 아래 배포는 사용자가 실제 운영하는 채널에서만 진행하며 계정·채널이 확인되지 않은 곳에는 임의 게시하지 않는다.

## 공통 원칙

- 네이버 블로그 원문을 먼저 오후 2시에 공개한다.
- Instagram은 각 카드가 다른 정보를 전달하는 경우에만 3~5장 순서형 캐러셀을 사용한다. Threads는 대표 카드 한 장과 원문 링크 하나로 줄인다.
- 외부 게시물은 답을 모두 복사하지 않고 원문의 체크리스트로 이동하게 한다.
- 고객 검색 글의 최종 링크는 `처음 방문 안내`로 통일한다.
- 창업·상품 전화번호는 고객용 외부 게시물에 넣지 않는다.
- 무작위 댓글, 대량 이웃 신청, 동일 문구 반복 배포를 하지 않는다.
- 아래 예약 원문 주소는 네이버에서 생성된 실제 글 번호다. 각 예약 시각 이후 공개 상태를 확인한 뒤에만 외부 채널에 사용한다.
- Facebook 페이지는 현재 비활성 상태이므로 재활성화와 계정 소유 확인 전까지 일정에서 제외한다.

## D+7 판정

각 원문은 발행 7일 뒤 아래 항목만 비교한다.

1. 중심 검색어 또는 새 연관 검색어 유입이 생겼는가
2. 원문 조회와 평균 사용 시간이 기준선보다 늘었는가
3. 처음 방문 안내 글 조회가 같은 기간에 함께 늘었는가
4. 카드 저장·공유·댓글·프로필 방문·링크 클릭이 있었는가
5. 어떤 카드와 문장이 반응을 만들었는가

검색 유입이 없으면 같은 주제 글을 추가하지 않는다. 제목·첫 120자·대표 이미지·내부 링크의 검색 의도 일치를 한 번만 재검토한다. 유입은 있으나 허브 이동이 없으면 마지막 행동 문구를 하나로 줄인다.
