# 큐사랑 소유 소셜 채널 프로필 문구

목적: 외부 카드뉴스에서 프로필을 방문한 사람이 고객·창업·상품 중 자신의 목적을 한 번에 선택하도록 한다. 실제 계정에 적용하기 전 계정 소유와 기존 소개 문구를 확인한다.

## 공통 프로필 링크

https://blog.naver.com/q_love_soul/224360799511

이 링크는 `큐사랑 처음 오셨다면, 염색·창업·상품 자료 안내` 공지로 연결된다. 개별 고객 정보 글을 프로필 링크로 매번 바꾸지 않고, 게시물 본문에서 해당 원문을 직접 연결한다.

### 9/14 Q-LOVE 연구 카드 한시 운영

- 9/14 19:20부터 9/15 19:30까지 Instagram 프로필 링크만 아래 근거 안내로 전환한다.
- 링크 제목: `Q-LOVE 제왕충초 근거 수준 안내`
- 링크 URL: `https://olove-research.kangbs2486.chatgpt.site/evidence`
- 카드 게시 전 공개 페이지가 로그인 없이 열리고 제목에 `큐사랑 Q-LOVE`가 정확히 표시되는지 확인한다.
- 24시간 측정이 끝나면 공통 프로필 링크인 `https://blog.naver.com/q_love_soul/224360799511`로 복원한다.
- Threads는 게시문 안에 `/evidence` 직접 링크를 한 번만 사용하므로 프로필 링크를 바꾸지 않는다.

## Instagram

- 표시 이름: `큐사랑 Q-LOVE | 염색방·헤어컬러`
- 소개:

```text
새치·뿌리염색 상담 전 확인할 정보
두피·모발 관리 · 염색방 창업 안내
Q-LOVE 제왕충초 연구·상품 자료는 아래 링크
```

- 링크 제목: `큐사랑 처음 방문·창업·상품 안내`
- 하이라이트 순서: `처음 방문` → `염색 질문` → `창업 안내` → `상품 자료`

## Threads

- 이름: `큐사랑 Q-LOVE | 염색방·헤어컬러`
- 소개:

```text
염색 전후 자주 묻는 질문과 Q-LOVE 제왕충초 연구 자료를 근거와 함께 정리합니다. 고객·창업·상품 안내는 프로필 링크에서 목적별로 확인하세요.
```

- 고정 후보: 오늘의 질문형 게시물 1개와 처음 방문 허브 안내 1개

- 페이지 이름: `큐사랑 Q-LOVE | 염색방·헤어컬러`
- 짧은 소개:

```text
새치·뿌리염색 상담 준비, 두피·모발 관리, 큐사랑 창업·상품 자료를 목적별로 안내합니다.
```

- 웹사이트: https://blog.naver.com/q_love_soul/224360799511
- 행동 버튼: 실제 운영 중인 예약·문의 채널이 확인되기 전에는 임의 번호나 예약 링크를 연결하지 않는다.

## 게시물별 링크 규칙

1. 고객 정보 게시물은 해당 질문의 블로그 원문 한 개만 연결한다.
2. 창업 게시물은 창업 허브와 `BLOG-START-01`을 사용한다.
3. 상품 게시물은 상품 허브와 `BLOG-PROD-01`을 사용한다.
4. 고객 정보 게시물에 창업 전화번호를 반복하지 않는다.
5. 지역·가격·예약 정보는 확인된 지점 자료가 있을 때만 사용한다.

## 적용 뒤 확인

- [ ] 표시 이름이 세 채널에서 동일하다.
- [ ] 공통 프로필 링크가 정확한 공개 공지를 연다.
- [ ] 모바일에서 소개 첫 두 줄에 `새치·뿌리염색`과 `처음 방문`이 보인다.
- [ ] 고객용 게시물에 창업 연락처가 섞이지 않았다.
- [ ] 각 채널의 링크 클릭 또는 프로필 방문 수를 기록할 수 있다.
