1. 검색 질문에 답하는 제목과 첫 문단
2. 해당 근거가 말해 주는 범위
3. 넘어가지 말아야 할 해석 경계
4. 읽기 전 확인할 질문 세 가지
5. 해당 유형 논문만 모은 내부 링크

## 공개 뒤 확인

1. 홈, `/evidence`, 세 세부 랜딩이 로그인 없이 HTTP 200인지 확인한다.
2. HTML 제목·설명·정규 URL이 페이지마다 서로 다른지 확인한다.
3. 사이트맵에 신규 4개 URL이 포함되고 전체 공개 정규 URL이 20개인지 확인한다.
4. 각 세부 랜딩의 논문 수가 3편·6편·5편인지 확인한다.
5. 논문 상세에서 해당 근거 랜딩으로 돌아갈 수 있는지 확인한다.
6. Q-LOVE 상품 문의 허브 링크가 `224360536630`으로 열리는지 확인한다.
7. 각 페이지를 공유했을 때 해당 근거 유형의 전용 이미지가 표시되는지 확인한다.
